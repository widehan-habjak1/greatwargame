# 그레이트 워 Great War

React와 TypeScript로 만든 2D 실시간 전장 지휘 시뮬레이션입니다. 플레이어는 부대와 편대를 운용하고, 정찰 정보와 보급 상태를 바탕으로 `무난하고 빠른 전면전` 시나리오를 지휘합니다.

## 주요 시스템

- 10,000 × 10,000 전장과 다단계 줌
- 보병·기계화·기갑·포병·정찰·공병
- 편대 구성과 선형·종대·쐐기 대형
- 이동·공격·사수·추종·정찰·수색·재보급 명령
- 사거리·장갑·명중률·발사체 기반 전투
- 순찰·방어·공격·증원·후퇴를 수행하는 적 지휘 AI
- 탐지·식별·접촉 소실 및 마지막 확인 위치
- 탄약·연료·보급망과 전투 지속 능력
- 동적 전선, 작전 목표, 승패 판정과 AAR
- LocalStorage 저장 및 불러오기

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

## 기본 조작

- 마우스 드래그: 카메라 이동
- 마우스 휠: 확대·축소
- 좌클릭: 부대 선택
- `Ctrl`/`Cmd` + 좌클릭: 다중 선택
- 우클릭: 선택 부대 이동
- `F`: 선택 부대로 카메라 이동
- `M`: 지도 모드 전환
- `L`: 보급망 표시
- `R`: 선택 부대 재보급
- `Space`: 일시정지
- `Esc`: 명령 또는 선택 취소

## 참고

전쟁 안개 그래픽은 현재 비활성화되어 있습니다. 적 부대의 탐지·식별·마지막 확인 위치 등 정보 제한 시스템은 계속 작동합니다.
